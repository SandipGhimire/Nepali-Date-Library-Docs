# Nepali Date Library 🇳🇵

A standardized, multi-language ecosystem for working with **Nepali (Bikram Sambat - BS)** dates. Available for **NodeJS / TypeScript**, **Python**, and **PHP**.

---

## Key Features

- **Bidirectional Conversion**: Convert between Gregorian (AD) and Bikram Sambat (BS) dates seamlessly.
- **Extensive Validation**: Validated calendar range from **1976/01/01 to 2100/12/31 BS**.
- **Date Arithmetic**: Add and subtract days, months, and years with automatic month-length handling.
- **Fiscal Year Calculation**: Built-in logic for Nepali fiscal years (Shrawan to Ashadh) and quarters.
- **Flexible Formatting**: Format dates with customizable tokens such as `YYYY-MM-DD`, `DD MMMM YYYY`, etc.
- **Consistent API**: Unified developer experience across Node.js, Python, and PHP.

## Quick Start

### Node.js (TypeScript / JavaScript)

```typescript
import { NepaliDate } from "nepali-date-library";

// Current date
const today = new NepaliDate();
console.log(today.format("YYYY-MM-DD")); // e.g. 2081-06-29

// Parse BS date
const date = new NepaliDate("2080-01-01");

// Convert to AD (JavaScript Date object)
const adDate = date.toJsDate();
console.log(adDate.toISOString());

// Date arithmetic
date.addDays(15);
console.log(date.format("DD MMMM YYYY"));
```

### Python

```python
from nepali_date_library import NepaliDate

# Current date
today = NepaliDate()
print(today.format("YYYY-MM-DD"))

# Parse specific BS date
date = NepaliDate("2080-01-01")

# Convert to AD
ad_date = date.to_datetime()
print(ad_date)

# Add days
date.add_days(15)
print(date.format("DD MMMM YYYY"))
```

### PHP

```php
use NepaliDateLibrary\NepaliDate;

// Current date
$date = new NepaliDate();
echo $date->format("YYYY-MM-DD");

// Parse specific date
$customDate = new NepaliDate("2080-01-01");

// Date manipulation
$customDate->addDays(15);
echo $customDate->format("DD MMMM YYYY");
```

## Supported Range

The library supports Bikram Sambat dates from **2000 BS to 2090+ BS** with verified month data spanning:

- **Bikram Sambat (BS)**: `1976/01/01` to `2100/12/31`
- Includes accurate leap years, differing month day counts, and official government calendar mappings.
