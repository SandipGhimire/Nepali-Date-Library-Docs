Standard calendar quarters divide the Bikram Sambat calendar year into four equal three month periods starting from 1 Baisakh. This guide clarifies the structural difference between standard calendar quarters and Nepal government fiscal year trimesters, which commence three months later on 1 Shrawan.

---

## Import

```typescript
import { NepaliDate } from "nepali-date-library";
```

```javascript
const { NepaliDate } = require("nepali-date-library");
```

---

## Signatures

```typescript
static getQuarter(
  quarter: number,
  year?: number
): { start: NepaliDate; end: NepaliDate };

static getQuarters(
  year?: number
): {
  Q1: { start: NepaliDate; end: NepaliDate };
  Q2: { start: NepaliDate; end: NepaliDate };
  Q3: { start: NepaliDate; end: NepaliDate };
  Q4: { start: NepaliDate; end: NepaliDate };
};
```

---

## Calendar Quarter Alignment

| Quarter | Months (Bikram Sambat) | Span |
| :--- | :--- | :--- |
| **Q1** | Baisakh, Jestha, Ashadh | 1 Baisakh – Last day of Ashadh |
| **Q2** | Shrawan, Bhadra, Ashwin | 1 Shrawan – Last day of Ashwin |
| **Q3** | Kartik, Mangsir, Poush | 1 Kartik – Last day of Poush |
| **Q4** | Magh, Falgun, Chaitra | 1 Magh – Last day of Chaitra |

## Examples

### Getting a Single Calendar Quarter

```typescript
import { NepaliDate } from "nepali-date-library";

// Q1 of calendar year 2081 (Baisakh to Ashadh)
const q1 = NepaliDate.getQuarter(1, 2081);
console.log(q1.start.format("YYYY-MM-DD")); // "2081-01-01"
console.log(q1.end.format("YYYY-MM-DD"));   // "2081-03-31"
```

### Getting All Four Calendar Quarters

```typescript
import { NepaliDate } from "nepali-date-library";

// Default year is current year
const quarters = NepaliDate.getQuarters(2081);

console.log("Q1:", quarters.Q1.start.format("YYYY-MM-DD"), "to", quarters.Q1.end.format("YYYY-MM-DD"));
console.log("Q2:", quarters.Q2.start.format("YYYY-MM-DD"), "to", quarters.Q2.end.format("YYYY-MM-DD"));
console.log("Q3:", quarters.Q3.start.format("YYYY-MM-DD"), "to", quarters.Q3.end.format("YYYY-MM-DD"));
console.log("Q4:", quarters.Q4.start.format("YYYY-MM-DD"), "to", quarters.Q4.end.format("YYYY-MM-DD"));
```
