The `endOfYear` method returns a new `NepaliDate` instance set to the closing day of the current Bikram Sambat calendar year. This corresponds to the final day of Chaitra, which is commonly needed for annual reconciliations and fiscal year preparations.

---

## Import

```typescript
import { NepaliDate } from "nepali-date-library";
```

---

## Signature

```typescript
endOfYear(): NepaliDate;
```

---

## Parameters

This method does not take any parameters.

---

## Return Value

* **Type**: `NepaliDate`
* Returns a new `NepaliDate` set to the last day of Chaitra for the given year at `23:59:59.999`. The original instance is not modified.

---

## Examples

### Getting the Final Day of the Calendar Year

```typescript
import { NepaliDate } from "nepali-date-library";

const date = new NepaliDate("2081-03-15");

const yearEnd = date.endOfYear();
console.log(yearEnd.format("YYYY-MM-DD")); // "2081-12-30"
console.log(yearEnd.getMonth()); // 11 (Chaitra)
console.log(yearEnd.getHours()); // 23
console.log(yearEnd.getMinutes()); // 59
console.log(yearEnd.getSeconds()); // 59
```

### Full Calendar Year Span

```typescript
import { NepaliDate } from "nepali-date-library";

const year = 2081;
const start = new NepaliDate(year, 0, 1).startOfDay();
const end = new NepaliDate(year, 0, 1).endOfYear();

console.log(`Year ${year} spans from ${start.format("YYYY-MM-DD")} to ${end.format("YYYY-MM-DD")}`);
```
