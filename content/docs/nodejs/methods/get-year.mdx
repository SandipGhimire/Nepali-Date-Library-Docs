Returns the 4-digit Bikram Sambat year of the current `NepaliDate` instance.

---

## Import

```typescript
import { NepaliDate } from "nepali-date-library";
```

---

## Signature

```typescript
getYear(): number;
```

---

## Parameters

* None.

---

## Return Value

* **Type**: `number`
* **Range**: `1976` to `2100`
* **Description**: Full 4-digit Bikram Sambat year integer.

---

## Example

```typescript
import { NepaliDate } from "nepali-date-library";

const date = new NepaliDate("2081-07-15");
console.log(date.getYear()); // 2081
```
