---
title: date.getDate()
description: Retrieve the numeric day of the month from a NepaliDate instance.
icon: Calendar
---

The `getDate` method returns the day of the month as an integer from 1 to 32 for the current `NepaliDate` instance. Unlike Gregorian months which have at most 31 days, Bikram Sambat calendar months can extend up to 32 days depending on the year and month.

---

## Import

```typescript
import { NepaliDate } from "nepali-date-library";
```

---

## Signature

```typescript
getDate(): number;
```

---

## Parameters

* None.

---

## Return Value

* **Type**: `number`
* **Range**: `1` to `32` (depending on the month and year).

---

## Example

```typescript
import { NepaliDate } from "nepali-date-library";

const date = new NepaliDate("2081-07-15");
console.log(date.getDate()); // 15
```
