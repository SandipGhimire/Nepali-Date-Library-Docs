Returns the day of the month for the current `NepaliDate` instance.

---

## Import

```typescript
import { NepaliDate } from "nepali-date-library";
```

---

## Signature

```typescript
getDate(): number;
```

---

## Parameters

* None.

---

## Return Value

* **Type**: `number`
* **Range**: `1` to `32` (depending on the month and year).

---

## Example

```typescript
import { NepaliDate } from "nepali-date-library";

const date = new NepaliDate("2081-07-15");
console.log(date.getDate()); // 15
```
