---

Returns the hour component (`0` to `23`) of the current `NepaliDate` instance.

---

## Import

```typescript
import { NepaliDate } from "nepali-date-library";
```

---

## Signature

```typescript
getHours(): number;
```

---

## Parameters

* None.

---

## Return Value

* **Type**: `number`
* **Range**: `0` to `23`

---

## Example

```typescript
import { NepaliDate } from "nepali-date-library";

const date = new NepaliDate();
console.log(date.getHours()); // e.g. 14
```
