description: API reference for the date.getMinutes() method.
icon: Clock
---

Returns the minute component (`0` to `59`) of the current `NepaliDate` instance.

---

## Import

```typescript
import { NepaliDate } from "nepali-date-library";
```

---

## Signature

```typescript
getMinutes(): number;
```

---

## Parameters

* None.

---

## Return Value

* **Type**: `number`
* **Range**: `0` to `59`

---

## Example

```typescript
import { NepaliDate } from "nepali-date-library";

const date = new NepaliDate();
console.log(date.getMinutes()); // e.g. 35
```
