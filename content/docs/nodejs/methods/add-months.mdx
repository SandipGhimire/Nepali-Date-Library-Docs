---
title: date.addMonths()
description: Add or subtract months to a NepaliDate instance while adjusting for variable month lengths.
icon: CalendarPlus
---

The `addMonths` method advances or rewinds the current `NepaliDate` instance by a specified number of months. If the current day of the month exceeds the total days available in the destination month, the method automatically clamps the day to the final valid day of that month to ensure calendar consistency.

---

## Import

```typescript
import { NepaliDate } from "nepali-date-library";
```

---

## Signature

```typescript
addMonths(months: number): NepaliDate;
```

---

## Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :---: | :--- |
| `months` | `number` | Yes | Number of months to add (positive) or subtract (negative). |

---

## Return Value

* **Type**: `NepaliDate`
* Returns a new `NepaliDate` instance with the added or subtracted months. The original instance is not modified.

---

## Exceptions

Throws an `Error` if the resulting year falls outside the supported Bikram Sambat calendar range (1976 BS to 2100 BS):

```typescript
"Resulting date is out of supported range"
```

---

## Examples

### Adding Months Within the Same Year

```typescript
import { NepaliDate } from "nepali-date-library";

// 2081 Baisakh 15 (month index 0)
const date = new NepaliDate(2081, 0, 15);

const future = date.addMonths(3);
console.log(future.format("YYYY-MM-DD")); // "2081-04-15" (Shrawan)
```

### Day Clamping on Shorter Months

When transitioning into a month with fewer days, the day component automatically adjusts to the maximum valid day of that target month:

```typescript
import { NepaliDate } from "nepali-date-library";

// 2081 Baisakh 31 (Baisakh has 31 days)
const date = new NepaliDate(2081, 0, 31);

// Jestha 2081 has 32 days -> day remains 31
const jestha = date.addMonths(1);
console.log(jestha.format("YYYY-MM-DD")); // "2081-02-31"

// Kartik 2081 has 30 days -> day is clamped to 30
const kartik = date.addMonths(6);
console.log(kartik.format("YYYY-MM-DD")); // "2081-07-30"
```

### Subtracting Months Across Year Boundaries

```typescript
import { NepaliDate } from "nepali-date-library";

// 2081 Baisakh 10
const date = new NepaliDate(2081, 0, 10);

const past = date.addMonths(-2);
console.log(past.format("YYYY-MM-DD")); // "2080-11-10" (Falgun 2080)
```
