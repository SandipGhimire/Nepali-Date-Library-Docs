---
title: date.getMilliseconds()
description: Retrieve the millisecond component from zero to nine hundred ninety nine.
icon: Clock
---

The `getMilliseconds` method returns the millisecond fraction of the current second as an integer from 0 to 999. It provides high resolution timing details for precision logging and event timestamping.

---

## Import

```typescript
import { NepaliDate } from "nepali-date-library";
```

---

## Signature

```typescript
getMilliseconds(): number;
```

---

## Parameters

* None.

---

## Return Value

* **Type**: `number`
* **Range**: `0` to `999`

---

## Example

```typescript
import { NepaliDate } from "nepali-date-library";

const date = new NepaliDate();
console.log(date.getMilliseconds()); // e.g. 512
```
