title: date.getMilliseconds()
description: API reference for the date.getMilliseconds() method.
icon: Clock
---

Returns the millisecond component (`0` to `999`) of the current `NepaliDate` instance.

---

## Import

```typescript
import { NepaliDate } from "nepali-date-library";
```

---

## Signature

```typescript
getMilliseconds(): number;
```

---

## Parameters

* None.

---

## Return Value

* **Type**: `number`
* **Range**: `0` to `999`

---

## Example

```typescript
import { NepaliDate } from "nepali-date-library";

const date = new NepaliDate();
console.log(date.getMilliseconds()); // e.g. 512
```
