---
title: NepaliDate.maximum()
description: Static method returning the maximum supported date boundary for the NepaliDate calendar engine.
icon: ArrowUpToLine
---

The `maximum` static method returns a native JavaScript Date object representing the latest Gregorian date supported by the library calendar engine. This corresponds to the final day of Chaitra in year 2100 BS and serves as an upper bound for date validation and calendar limits.

---

## Import

```typescript
import { NepaliDate } from "nepali-date-library";
```

---

## Signature

```typescript
static maximum(): Date;
```

---

## Parameters

This method does not take any parameters.

---

## Return Value

* **Type**: `Date`
* Returns a standard JavaScript `Date` instance representing the absolute upper limit of the calendar mapping dataset.

---

## Examples

### Checking Upper Calendar Limit

```typescript
import { NepaliDate } from "nepali-date-library";

const maxDate = NepaliDate.maximum();
console.log(maxDate.toISOString());

// Converting maximum back to NepaliDate
const nepaliMax = new NepaliDate(maxDate);
console.log(nepaliMax.format("YYYY-MM-DD")); // "2100-12-30" (or 31)
```
