---
title: NepaliDate.minimum()
description: Static method returning the minimum supported date boundary for the NepaliDate calendar engine.
icon: ArrowDownToLine
---

The `minimum` static method returns a native JavaScript Date object representing the earliest Gregorian date supported by the library calendar engine. This corresponds to the first day of Baisakh in year 1976 BS and provides a reliable lower boundary for date pickers and form input validation.

---

## Import

```typescript
import { NepaliDate } from "nepali-date-library";
```

---

## Signature

```typescript
static minimum(): Date;
```

---

## Parameters

This method does not take any parameters.

---

## Return Value

* **Type**: `Date`
* Returns a standard JavaScript `Date` instance representing the minimum boundary (`1919-04-13T00:00:00.000Z`).

---

## Examples

### Checking Lower Calendar Limit

```typescript
import { NepaliDate } from "nepali-date-library";

const minDate = NepaliDate.minimum();
console.log(minDate.toISOString()); // "1919-04-13T00:00:00.000Z"

// Converting minimum back to NepaliDate
const nepaliMin = new NepaliDate(minDate);
console.log(nepaliMin.format("YYYY-MM-DD")); // "1976-01-01"
```
