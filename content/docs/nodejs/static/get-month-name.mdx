---
title: NepaliDate.getMonthName()
description: API reference for the static NepaliDate.getMonthName() method.
icon: Type
---

Returns the localized name of a Bikram Sambat month in English or Devanagari (Nepali), supporting both full and abbreviated formats.

---

## Import

```typescript
import { NepaliDate } from "nepali-date-library";
```

---

## Signature

```typescript
static getMonthName(month: number, short?: boolean, nepali?: boolean): string;
```

---

## Parameters

| Parameter | Type | Required | Default | Description |
| :--- | :--- | :---: | :---: | :--- |
| `month` | `number` | Yes | - | Zero-indexed month number (`0-11`, where `0` is Baisakh). |
| `short` | `boolean` | No | `false` | When `true`, returns the 3-letter abbreviated name. |
| `nepali` | `boolean` | No | `false` | When `true`, returns the name in Devanagari script. |

---

## Return Value

* **Type**: `string`
* Localized month name string.

---

## Exceptions

Throws an `Error` if `month` is less than `0` or greater than `11`:

```typescript
"Invalid month index, must be between 0-11"
```

## Examples

### Generating Localized Month Labels

```typescript
import { NepaliDate } from "nepali-date-library";

// Default English Full
console.log(NepaliDate.getMonthName(0)); // "Baisakh"

// English Short
console.log(NepaliDate.getMonthName(0, true)); // "Bai"

// Nepali Devanagari Full
console.log(NepaliDate.getMonthName(0, false, true)); // "बैशाख"

// Nepali Devanagari Short
console.log(NepaliDate.getMonthName(0, true, true)); // "बै"
```
