An array containing the standard full English names of the 7 days of the week, indexed `0` (Sunday) through `6` (Saturday).

---

## Import

```typescript
import { WEEK_EN } from "nepali-date-library";
```

---

## Value

```typescript
export const WEEK_EN = [
  "Sunday",
  "Monday",
  "Tuesday",
  "Wednesday",
  "Thursday",
  "Friday",
  "Saturday",
];
```

---

## Index Mapping

| Index | Day Name |
| :---: | :--- |
| `0` | `"Sunday"` |
| `1` | `"Monday"` |
| `2` | `"Tuesday"` |
| `3` | `"Wednesday"` |
| `4` | `"Thursday"` |
| `5` | `"Friday"` |
| `6` | `"Saturday"` |

---

## Examples

### Getting Current Weekday Name

```typescript
import { WEEK_EN, NepaliDate } from "nepali-date-library";

const date = new NepaliDate("2081-01-25");
console.log(WEEK_EN[date.getDay()]); // "Thursday"
```
