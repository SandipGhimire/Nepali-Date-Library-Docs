---
title: WEEK_EN
description: Array containing full English names for all seven days of the week starting from Sunday.
icon: CalendarDays
---

The `WEEK_EN` constant is an array containing the full English weekday names ordered from Sunday at index 0 through Saturday at index 6. This ordering matches the standard JavaScript day index convention returned by the getDay method, allowing seamless weekday lookups in English interfaces.

---

## Import

```typescript
import { WEEK_EN } from "nepali-date-library";
```

---

## Value

```typescript
export const WEEK_EN = [
  "Sunday",
  "Monday",
  "Tuesday",
  "Wednesday",
  "Thursday",
  "Friday",
  "Saturday",
];
```

---

## Index Mapping

| Index | Day Name |
| :---: | :--- |
| `0` | `"Sunday"` |
| `1` | `"Monday"` |
| `2` | `"Tuesday"` |
| `3` | `"Wednesday"` |
| `4` | `"Thursday"` |
| `5` | `"Friday"` |
| `6` | `"Saturday"` |

---

## Examples

### Getting Current Weekday Name

```typescript
import { WEEK_EN, NepaliDate } from "nepali-date-library";

const date = new NepaliDate("2081-01-25");
console.log(WEEK_EN[date.getDay()]); // "Thursday"
```
