---
title: WEEK_SHORT_EN
description: Array containing abbreviated English weekday names ordered from Sunday through Saturday.
icon: CalendarDays
---

The `WEEK_SHORT_EN` constant contains short three letter English abbreviations for each day of the week, starting with Sun at index 0 and ending with Sat at index 6. These concise labels are widely used in monthly calendar headers, compact date selectors, and agenda views.

---

## Import

```typescript
import { WEEK_SHORT_EN } from "nepali-date-library";
```

---

## Value

```typescript
export const WEEK_SHORT_EN = [
  "Sun",
  "Mon",
  "Tue",
  "Wed",
  "Thu",
  "Fri",
  "Sat",
];
```

---

## Index Mapping

| Index | Abbreviation | Full Name |
| :---: | :--- | :--- |
| `0` | `"Sun"` | Sunday |
| `1` | `"Mon"` | Monday |
| `2` | `"Tue"` | Tuesday |
| `3` | `"Wed"` | Wednesday |
| `4` | `"Thu"` | Thursday |
| `5` | `"Fri"` | Friday |
| `6` | `"Sat"` | Saturday |

---

## Examples

### Building Calendar Column Headers

```typescript
import { WEEK_SHORT_EN } from "nepali-date-library";

// Generate week header row for UI calendar
console.log(WEEK_SHORT_EN.join(" | "));
// "Sun | Mon | Tue | Wed | Thu | Fri | Sat"
```
