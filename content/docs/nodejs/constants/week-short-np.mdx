---
title: WEEK_SHORT_NP
description: Array containing short Devanagari abbreviations for each day of the week starting from Sunday.
icon: CalendarDays
---

The `WEEK_SHORT_NP` constant supplies short Devanagari abbreviations for each day of the week, beginning with index 0 for Aaitabar and ending with index 6 for Shanibar. These compact symbols are ideal for calendar grid headers and mobile date selectors where horizontal width is limited.

---

## Import

```typescript
import { WEEK_SHORT_NP } from "nepali-date-library";
```

---

## Value

```typescript
export const WEEK_SHORT_NP = [
  "आइत",
  "सोम",
  "मंगल",
  "बुध",
  "बिहि",
  "शुक्र",
  "शनि",
];
```

---

## Index Mapping

| Index | Short Name | Full Name | English Equivalent |
| :---: | :--- | :--- | :--- |
| `0` | `"आइत"` | आइतबार | Sunday |
| `1` | `"सोम"` | सोमबार | Monday |
| `2` | `"मंगल"` | मंगलबार | Tuesday |
| `3` | `"बुध"` | बुधबार | Wednesday |
| `4` | `"बिहि"` | बिहिबार | Thursday |
| `5` | `"शुक्र"` | शुक्रबार | Friday |
| `6` | `"शनि"` | शनिबार | Saturday |

---

## Examples

### Building Calendar Column Headers in Devanagari

```typescript
import { WEEK_SHORT_NP } from "nepali-date-library";

// Generate week header row for UI calendar
console.log(WEEK_SHORT_NP.join(" | "));
// "आइत | सोम | मंगल | बुध | बिहि | शुक्र | शनि"
```
