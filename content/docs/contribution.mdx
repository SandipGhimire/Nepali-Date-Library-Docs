Thank you for your interest in contributing to the **Nepali Date (Bikram Sambat) Ecosystem**! This open-source project is built and maintained to provide synchronized, robust, zero-dependency calendar tools across JavaScript/TypeScript, Python, and PHP.

Whether you are fixing a typo, adding calendar tests, improving performance, or porting new features across languages, your contributions are warmly welcomed.

## Core Contribution Principles

Before proposing changes, please keep our core architectural principles in mind:

1. **Zero External Runtime Dependencies**:
   All three language packages (`nepali-date-library`) MUST maintain zero external dependencies at runtime. Do not add runtime packages.

2. **Standardized Cross-Language Semantics**:
   The API surface across Node.js, Python, and PHP is intentionally synchronized. Method names, formatting tokens (e.g. `YYYY-MM-DD`, `dddd`), fiscal year quarters, and edge case handling should match across all implementations.

3. **Certified Range Accuracy (1976 – 2100 BS)**:
   Any changes affecting date conversion or calendar math must pass the exhaustive ephemeris verification tests covering 1976/01/01 to 2100/12/31 BS.

4. **Deterministic Timezone Isolation**:
   Date arithmetic, weekday getters, and day start/end calculations must execute deterministically regardless of the host machine's local timezone.

## Development Environment Setup

Select your target language below for environment setup and test commands:

<Tabs items={["Node.js / TypeScript", "Python", "PHP", "Documentation"]}>
  <Tab value="Node.js / TypeScript">
    ### Node.js / TypeScript Setup

    **Prerequisites**: Node.js `>= 22.0.0`, pnpm `>= 10.0.0`

    ```bash
    # Clone repository
    git clone https://github.com/SandipGhimire/Nepali-Date-Library-NodeJS.git
    cd Nepali-Date-Library-NodeJS

    # Install dependencies
    pnpm install

    # Build ESM and CJS bundles
    pnpm run build

    # Run tests (Vitest)
    pnpm run test

    # Run legacy Node compatibility tests (Node 8-17)
    pnpm run test:compat

    # Lint and formatting
    pnpm run lint
    pnpm run format
    ```
  </Tab>

  <Tab value="Python">
    ### Python Setup

    **Prerequisites**: Python `>= 3.9`, [uv](https://docs.astral.sh/uv/) (recommended)

    ```bash
    # Clone repository
    git clone https://github.com/SandipGhimire/Nepali-Date-Library-Python.git
    cd Nepali-Date-Library-Python

    # Create virtual environment and install dev dependencies
    uv sync --group dev

    # Run unit tests and style checks
    uv run task test

    # Or run pytest directly
    uv run pytest

    # Format code with black
    uv run black src tests

    # Static type checking
    uv run mypy src
    ```
  </Tab>

  <Tab value="PHP">
    ### PHP Setup

    **Prerequisites**: PHP `>= 7.1`, [Composer](https://getcomposer.org/)

    ```bash
    # Clone repository
    git clone https://github.com/SandipGhimire/Nepali-Date-Library-PHP.git
    cd Nepali-Date-Library-PHP

    # Install dependencies
    composer install

    # Run full PHPUnit test suite
    composer test
    ```
  </Tab>

  <Tab value="Documentation">
    ### Documentation Engine Setup

    **Prerequisites**: Node.js `>= 22.0.0`, pnpm `>= 10.0.0`

    ```bash
    # Navigate to Docs directory in main repo
    cd Docs

    # Install dependencies
    pnpm install

    # Start development server with Turbopack
    pnpm dev
    ```

    Open [http://localhost:3000](http://localhost:3000) to view local live edits with instant hot reload.
  </Tab>
</Tabs>

## Pull Request Guidelines

1. **Fork & Branch**: Fork the target repository and create a descriptive branch:
   ```bash
   git checkout -b feat/devanagari-weekday-tokens
   ```
2. **Write Tests**: Accompany every bug fix or feature with clear unit tests verifying the behavior.
3. **Run CI Checks**: Verify that all test suites, linters, and type checkers pass without errors.
4. **Descriptive Commits**: Use conventional commits (e.g., `feat:`, `fix:`, `docs:`, `chore:`).
5. **Submit PR**: Open a Pull Request referencing any related issues with reproduction steps or rationale.
