title: date.is_after()
description: Check whether the current date occurs chronologically after another specified date.
icon: Clock
---

The `is_after` method evaluates whether the current `NepaliDate` instance occurs chronologically later than another date or timestamp. It compares exact millisecond values to determine chronological order accurately.

---

## Import

```python
from nepali_date_library import NepaliDate
```

---

## Signature

```python
def is_after(self, date: NepaliDate) -> bool:
```

---

## Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :---: | :--- |
| `date` | `NepaliDate` | Yes | Target date to compare against. |

---

## Return Value

* **Type**: `bool`
* **Description**: Returns `True` if `self` is chronologically later than `date`.

---

## Example

```python
from nepali_date_library import NepaliDate

d1 = NepaliDate("2081-01-15")
d2 = NepaliDate("2081-01-01")

print(d1.is_after(d2)) # True
```
