The `end_of_year` method returns a new `NepaliDate` instance set to the closing day of the current Bikram Sambat calendar year. This corresponds to the final day of Chaitra, which is commonly needed for annual reconciliations and fiscal year preparations.

---

## Import

```python
from nepali_date_library import NepaliDate
```

---

## Signature

```python
def end_of_year(self) -> NepaliDate:
```

---

## Parameters

* None.

---

## Return Value

* **Type**: `NepaliDate`
* **Description**: New date instance on the final day of Chaitra.

---

## Example

```python
from nepali_date_library import NepaliDate

date = NepaliDate("2081-07-15")
year_end = date.end_of_year()
print(year_end.format("YYYY-MM-DD")) # "2081-12-30" or similar
```
