The `is_valid_instance` method checks whether the current `NepaliDate` instance contains valid calendar values and falls within the supported range of 1976 through 2100 BS. It verifies that year, month, and day coordinates correspond to an authentic historical date.

---

## Import

```python
from nepali_date_library import NepaliDate
```

---

## Signature

```python
def is_valid_instance(self) -> bool:
```

---

## Parameters

* None.

---

## Return Value

* **Type**: `bool`
* **Description**: Returns `True` if the date is valid.

---

## Example

```python
from nepali_date_library import NepaliDate

date = NepaliDate("2081-07-15")
print(date.is_valid_instance()) # True
```
