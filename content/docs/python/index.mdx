## Quick Start

```python
from nepali_date import NepaliDate

# 1. Current Nepali date
today = NepaliDate.today()
print(today.format("%Y-%m-%d"))  # e.g. "2081-06-29"

# 2. Specific BS date
event = NepaliDate(2081, 7, 15)
print(event.format("%A, %B %d, %Y"))  # "Friday, Kartik 15, 2081"

# 3. Convert to Python datetime (Gregorian AD)
ad_date = event.to_ad()
print(ad_date.strftime("%Y-%m-%d"))  # "2024-10-31"

# 4. Standalone conversion helpers
from nepali_date import ad_to_bs, bs_to_ad

bs = ad_to_bs("2024-11-15")  # "2081-07-30"
ad = bs_to_ad("2081-07-30")  # "2024-11-15"
```

## Core Capabilities

- **Pythonic Paradigm**: Native integration with standard `datetime.date` and `timedelta` patterns.
- **Accurate Conversions**: Verified astronomical lookup matrices spanning 1976 to 2100 BS.
- **Type Annotations**: Comprehensive type hints for mypy validation and IDE autocompletion.
- **Fiscal Calculations**: Query fiscal quarter and fiscal year strings directly.
- **Devanagari Localization**: Render Nepali numerals and script natively.
