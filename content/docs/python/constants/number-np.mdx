The `number_np` constant is an array containing the ten Devanagari numeral characters representing digits 0 through 9 in Nepali script. It provides a direct lookup table for formatting numbers, years, dates, and currency values into native Devanagari script for Nepali language interfaces.

---

## Import

```python
from nepali_date_library import number_np
```

---

## Value

```python
number_np = ["०", "१", "२", "३", "४", "५", "६", "७", "८", "९"]
```

## Examples

### Converting Digits to Devanagari

```python
from nepali_date_library import number_np

def to_devanagari(number: int) -> str:
    return "".join(number_np[int(digit)] for digit in str(number))

print(to_devanagari(2081)) # "२०८१"
```
