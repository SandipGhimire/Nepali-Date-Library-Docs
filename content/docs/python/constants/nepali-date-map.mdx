The `nepali_date_map` data structure contains the calendar matrix for the Bikram Sambat system spanning years 1976 through 2100 BS. Because Bikram Sambat months have variable day counts determined by astronomical solar calculations rather than fixed rules, this mapping table provides the definitive source of truth for conversions, day calculations, and month lengths.

> [!NOTE]
> Dates up to the active calendar year are verified against official publications from the **Nepal Panchanga Nirnayak Samiti** (नेपाल पञ्चाङ्ग निर्णायक समिति). Every year around the month of **Ashwin (Ashoj)**, when the official government calendar is gazetted for the subsequent year, this mapping table is audited and updated with exact solar ingress corrections.

---

## Import

```python
from nepali_date_library import nepali_date_map
```

---

## Structure

Each entry in `nepali_date_map` is a dictionary containing year metadata and day counts:

```python
from typing import TypedDict, List

class NepaliDateEntry(TypedDict):
    year: int
    days: List[int]
    totalDays: int
    daysTillNow: int

nepali_date_map: List[NepaliDateEntry]
```

---

## Field Reference

| Field | Type | Description |
| :--- | :--- | :--- |
| `year` | `int` | The Bikram Sambat year integer between 1976 and 2100 BS. |
| `days` | `List[int]` | Twelve integers specifying the exact day counts for each month from Baisakh to Chaitra. |
| `totalDays` | `int` | Total cumulative days in that specific calendar year. |
| `daysTillNow` | `int` | Cumulative day offset since the calendar epoch. |

---

## Example Usage

```python
from nepali_date_library import nepali_date_map

# Retrieve data for year 2081 BS
year_2081 = next(item for item in nepali_date_map if item["year"] == 2081)
print(f"Year: {year_2081['year']}")
print(f"Month day counts: {year_2081['days']}")

# Day count for Baisakh (index 0) in 2081 BS
baisakh_days = year_2081["days"][0]
print(f"Days in Baisakh 2081: {baisakh_days}")
```
