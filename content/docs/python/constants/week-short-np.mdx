The `week_short_np` constant supplies short Devanagari abbreviations for each day of the week, beginning with index 0 for Aaitabar and ending with index 6 for Shanibar. These compact symbols are ideal for calendar grid headers and mobile date selectors where horizontal width is limited.

---

## Import

```python
from nepali_date_library import week_short_np
```

---

## Value

```python
week_short_np = [
    "आ",
    "सो",
    "मं",
    "बु",
    "बि",
    "शु",
    "श",
]
```

---

## Weekday Abbreviation Table

| Index | Short Devanagari | Full Devanagari | English |
| :---: | :--- | :--- | :--- |
| `0` | `आ` | आइतबार | Sunday |
| `1` | `सो` | सोमबार | Monday |
| `2` | `मं` | मंगलबार | Tuesday |
| `3` | `बु` | बुधबार | Wednesday |
| `4` | `बि` | बिहिबार | Thursday |
| `5` | `शु` | शुक्रबार | Friday |
| `6` | `श` | शनिबार | Saturday |

---

## Example Usage

```python
from nepali_date_library import NepaliDate, week_short_np

date = NepaliDate("2081-07-15")
print(week_short_np[date.get_day()]) # "शु"
```
