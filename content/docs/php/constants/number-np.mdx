The `Constants::$NUMBER_NP` constant is an array containing the ten Devanagari numeral characters representing digits 0 through 9 in Nepali script. It provides a direct lookup table for formatting numbers, years, dates, and currency values into native Devanagari script for Nepali language interfaces.

---

## Import

```php
use NepaliDateLibrary\Helper\Constants;
```

---

## Value

```php
Constants::$NUMBER_NP = ["०", "१", "२", "३", "४", "५", "६", "७", "८", "९"];
```

## Examples

```php
use NepaliDateLibrary\Helper\Constants;

function toDevanagari(int $number): string
{
    $digits = str_split((string) $number);
    return implode('', array_map(function ($d) {
        return Constants::$NUMBER_NP[(int) $d];
    }, $digits));
}

echo toDevanagari(2081); // "२०८१"
```
