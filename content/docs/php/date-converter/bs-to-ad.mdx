---
title: BStoAD()
description: Pure helper function to convert Bikram Sambat date strings into Gregorian calendar date strings.
icon: ArrowLeft
---

The `BStoAD` function converts a Bikram Sambat date string into its equivalent Gregorian calendar date string. It validates the input Nepali date against verified historical calendar maps and returns a formatted Gregorian date string suitable for storage in standard SQL databases or transmission over web APIs.

---

## Import

```php
use function NepaliDateLibrary\BStoAD;
```

---

## Signature

```php
function BStoAD(string $bsDate): string;
```

---

## Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :---: | :--- |
| `$bsDate` | `string` | Yes | Bikram Sambat date string formatted strictly as `YYYY-MM-DD`. |

---

## Return Value

* **Type**: `string`
* **Format**: `YYYY-MM-DD` representing the equivalent Gregorian calendar date.

---

## Exceptions

| Exception Class | Trigger Condition |
| :--- | :--- |
| `InvalidArgumentException` | Thrown if input does not match format `YYYY-MM-DD` or has out of range year, month, or day values. |
| `RuntimeException` | Thrown if the conversion calculation fails unexpectedly. |

---

## Examples

### Basic Conversion

```php
use function NepaliDateLibrary\BStoAD;

$gregorianDate = BStoAD('2080-01-01');
echo $gregorianDate; // "2023-04-14"
```

### Storing in SQL Databases

```php
$userInputBs = '2081-07-15';
$databaseAdDate = BStoAD($userInputBs);
echo $databaseAdDate; // "2024-10-31"
```
