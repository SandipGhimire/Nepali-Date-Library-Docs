title: date->startOfYear()

icon: Calendar
---

The `startOfYear` method returns a new `NepaliDate` instance set to 1 Baisakh, the first day of the Bikram Sambat calendar year. This is useful for year to date financial tracking and annual summary reports.

---

## Import

```php
use NepaliDateLibrary\NepaliDate;
```

---

## Signature

```php
public function startOfYear(): self;
```

---

## Parameters

* None.

---

## Return Value

* **Type**: `NepaliDate`
* **Description**: New date instance positioned on 1 Baisakh of the current year.

---

## Example

```php
use NepaliDateLibrary\NepaliDate;

$date = new NepaliDate('2081-07-15');
$yearStart = $date->startOfYear();
echo $yearStart->format('YYYY-MM-DD'); // "2081-01-01"
```
