---
title: date->parse()
description: Parse a formatted Bikram Sambat date string and update the current date instance in place.
icon: FileText
---

The `parse` method parses a Bikram Sambat date string and updates the coordinates of the current `NepaliDate` instance in place. It supports various delimiter styles including slashes, dots, and hyphens, recalculating the underlying timestamp upon successful parsing.

---

## Import

```php
use NepaliDateLibrary\NepaliDate;
```

---

## Signature

```php
public function parse(string $dateString): void;
```

---

## Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :---: | :--- |
| `$dateString` | `string` | Yes | Formatted Bikram Sambat date string (e.g. `'2081-07-15'`). |

---

## Return Value

* **Type**: `void`
* **Note**: Mutates the current instance in place.

---

## Example

```php
use NepaliDateLibrary\NepaliDate;

$date = new NepaliDate();
$date->parse('2081-07-15');
echo $date->format('YYYY-MM-DD'); // "2081-07-15"
```
