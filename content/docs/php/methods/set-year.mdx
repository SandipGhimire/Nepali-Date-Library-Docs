---
title: date->setYear()
description: Set the Bikram Sambat year on a NepaliDate instance within the supported calendar range.
icon: Edit3
---

The `setYear` method updates the four digit Bikram Sambat year on the current `NepaliDate` instance and adjusts the timestamp accordingly. The target year must fall within the supported range between 1976 and 2100 BS.

---

## Import

```php
use NepaliDateLibrary\NepaliDate;
```

---

## Signature

```php
public function setYear(int $year): void;
```

---

## Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :---: | :--- |
| `$year` | `int` | Yes | Target Bikram Sambat year between 1976 and 2100. |

---

## Return Value

* **Type**: `void`
* **Note**: Mutates the current instance in place.

---

## Example

```php
use NepaliDateLibrary\NepaliDate;

$date = new NepaliDate('2080-07-15');
$date->setYear(2081);
echo $date->format('YYYY-MM-DD'); // "2081-07-15"
```
