The nepali date library is distributed as a standard Composer package on Packagist with zero external dependencies. It works seamlessly across modern PHP versions and integrates directly with Laravel, Symfony, WordPress, and standalone PHP projects.

---

## Package Installation

<Tabs items={["composer"]}>
  <Tab value="composer">

```bash
composer require sghimire/nepali-date-library
```
  </Tab>

---

## Composer Configuration

Add the package dependency to your `composer.json` file manually if preferred:

```json
{
  "require": {
    "sghimire/nepali-date-library": "^1.0"
  }
}
```

Then run `composer update` or `composer install` to download the package.

---

## Autoloading

Include the Composer generated autoload script at the entry point of your PHP script:

```php
<?php

require __DIR__ . '/vendor/autoload.php';

use NepaliDateLibrary\NepaliDate;

$date = new NepaliDate();
echo $date->format('YYYY-MM-DD');
```
