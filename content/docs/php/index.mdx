The Nepali Date Library for PHP provides a modern object oriented toolkit with zero external dependencies for Bikram Sambat calendar operations. It handles bidirectional conversion between Bikram Sambat and Gregorian calendars, date arithmetic, custom string formatting, fiscal year calculations, and calendar grid generation for PHP web applications and enterprise systems.

## Installation

Install the package via Composer:

```bash
composer require sghimire/nepali-date-library
```

---

## Quick Example

```php
<?php

require 'vendor/autoload.php';

use NepaliDateLibrary\NepaliDate;
use function NepaliDateLibrary\ADtoBS;
use function NepaliDateLibrary\BStoAD;

// Current Nepali date
$today = new NepaliDate();
echo $today->format('YYYY-MM-DD');

// Specific Bikram Sambat date (month 0 is Baisakh)
$event = new NepaliDate(2081, 6, 15);
echo $event->format('dddd, MMMM DD, YYYY');

// Standalone date conversion helpers
$bsDate = ADtoBS('2024-11-15');
$adDate = BStoAD('2081-07-30');
```

## Feature Matrix

| Feature | Support | Description |
| :--- | :---: | :--- |
| **Bikram Sambat Calendar Engine** | Yes | Verified calendar matrix spanning years 1976 through 2100 BS. |
| **Bidirectional AD to BS Conversion** | Yes | Standalone conversion functions and full object instances. |
| **Date Arithmetic** | Yes | Add and subtract days, months, and years with automatic rollover. |
| **Fiscal Year Operations** | Yes | Official Nepalese fiscal calendar starting on 1 Shrawan. |
| **Custom Format Patterns** | Yes | Token formatting for year, month, weekday, and Devanagari script. |
| **Calendar Grid Builder** | Yes | Forty two cell matrix generation for calendar interfaces. |
