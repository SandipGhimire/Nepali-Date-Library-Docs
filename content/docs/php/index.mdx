## Quick Start

```php
<?php

require 'vendor/autoload.php';

use NepaliDate\NepaliDate;

// 1. Current Nepali date
$nepaliDate = new NepaliDate();
echo $nepaliDate->format('Y-m-d'); // e.g. 2081-06-29

// 2. Parse specific BS date
$event = new NepaliDate('2081-07-15');
echo $event->format('l, F j, Y'); // "Friday, Kartik 15, 2081"

// 3. Convert to Gregorian (AD)
$adDate = $event->toAD(); // "2024-10-31"

// 4. Standalone conversion helpers
use function NepaliDate\ad_to_bs;
use function NepaliDate\bs_to_ad;

$bs = ad_to_bs('2024-11-15'); // "2081-07-30"
$ad = bs_to_ad('2081-07-30'); // "2024-11-15"
```

## Core Capabilities

- **Modern PHP Standards**: Strict typing, PSR compliance, and full support for PHP 8.0 to 8.4+.
- **Bidirectional Conversion**: Accurate, validated conversions between AD and BS spanning 1976 to 2100 BS.
- **Date Arithmetic**: Fluent methods (`addDays`, `subDays`, `addMonths`, `subMonths`) with month-end boundary clamping.
- **Fiscal Calendar Engine**: Automatic resolution of Nepali fiscal years (e.g. `2081/82`) and quarters.
- **Localization**: Supports formatting in English and Nepali Devanagari script.
