# Nepali Date Library Documentation 🇳🇵

The documentation website for the [Nepali Date Library](https://github.com/SandipGhimire/Nepali-Date-Library). Built with [Next.js](https://nextjs.org) and [Fumadocs](https://fumadocs.dev).

## Development

```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev

# Build for production
pnpm build
```
